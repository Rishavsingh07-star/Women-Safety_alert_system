# 🛡️Women Safety Alert System

A simple Python project that helps women in emergency situations 
by triggering an SOS alert and logging it with timestamp.

---

##  About the Project

This project was made as part of my 1st year CSE course.
It is a console-based Python application focused on women safety.

---

##  Features

- One-key SOS alert trigger
- Displays emergency contact details
- Shows important safety tips
- Saves every alert to a log file with date and time

---

## Technologies Used

- Python 3
- datetime module (built-in)
- File Handling

---

## ▶️ How to Run

1. Install Python from https://python.org
2. Download `safety_alert.py`
3. Open terminal and run:
   python safety_alert.py

---

## 📋 Menu Options

| Option | Action |
|--------|--------|
| 1 | Trigger SOS Alert |
| 2 | View Safety Tips |
| 3 | Exit |
